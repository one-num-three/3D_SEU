# 九龙湖校园 v21 · 桃园3–8二十四栋梯形错误纠正

本批以v20为基底，只纠正24条宿舍的历史XY配准变形。96对象同名替换，总4276主网格不变，4180其余对象保持；20看台、19宿舍端部/田径、桥与道路不退回。本文件不代表网站已经发布。

## 为什么可以改矩形
逐栋接受OSM轮廓矩形率99.58%–99.88%，旧body仅82.4%–84.9%，是旧复用注册拉成梯形，不是全部实楼恰好梯形。只对这24条有明确几何依据的近矩形纠正；没有把梅园/橘园或任意不规则楼一概拉直。原OSM边界、stable ID、楼间次序与坐标原点不改。

解原梯形并在原轮廓内缩0.60m建立矩形主体/细倒角；窗和檐口重新贴合正确外墙。质心在既有plot内回正最大约0.641m，属于纠错，不称原XY完全不动。原对象Z上下界、110窗/五排的旧数值保留，这仍是继承模型而非逐栋实测窗数。没有凭空补坡顶、入口或阳台。

## 材质和艺术边界
正式`assets/SEU_building_patch_v21.glb`从整合工程导出，使用v20原材料数据块，全部4276对象PBR参数保持；不是`dorm24/corrected/dorm_sample.glb`的统一roughness0.65审查材质。审查小GLB只作几何对照，不能拿它覆盖正式版本。

**不含**用户尚在审查的四栋竖条/阳台/雨棚艺术试验，也不含C沙盘试验；本批是拟真主版真实错误纠正，尚未解决每栋外观差异化和完整精修。

## 使用
按`data/REPLACEMENT_MANIFEST.json`精确96→96，source SHA+name+stable ID对应当前可见对象后再替换，禁止同名重复追加。保持fixed14缓存与15–20全部增量，21可无损压缩，不强制旧用户重下整校。

运行`python scripts/unpack_full_source.py`恢复完整`assets/SEU_campus_full_quality_v21.blend`；分卷无损，不减面。地表v04、树603和独立B2依旧分层。本地米制EPSG32650原点E671709.6990725585/N3529586.400278158；Blender东/北/上、glTF东/上/南，不是实测竖向高程。

`dorm24/`含原始/修正几何数据库、OSM输入、逐栋变换与QA、复建脚本和前后图；可不依赖私人照片复建。`scripts/integrate_checkpoint.py -- <完整v20源>`验证96原指纹后生成独立新工程，源文件不覆盖。

## 验证与限制
24细部投影在OSM内、Z边界不变、生产GLB冷导入96、完整源4276冷开、4180其它几何/材质保留、96原PBR槽保持、退化面检查。手机FPS/动态闪烁仍未实机验收，未知门洞、层数、室内和外围路口接缝问题未冒称完成。
