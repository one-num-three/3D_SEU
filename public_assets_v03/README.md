# 九龙湖 v0.3：生医南向修正与旧建筑恢复

本版修复了v0.2遗漏的多组旧建筑细部，不是把“体块样板”当作完成。**它仍不是全校精确复建或实测模型。** v0.1/v0.2保留回退，不改变共同坐标和道路。

## 打开
- `assets/SEU_campus_restored_v03.blend`：完整独立工程，Blender4.3或兼容版本可直接打开，无外部资源依赖。
- `assets/SEU_campus_restored_v03_GLB.zip`：解压后是一个完整GLB；未拆面、未降模。原始GLB大小和SHA见 `assets/GLB_ARCHIVE.json`。GitHub普通文件页不保证直接展示3D。
- 每个新增模块另有可直接导入的GLB；同一米制坐标，导入时不要居中、旋转、缩放。

![当前整体](previews/CAMPUS_OBLIQUE.png)

**图例**：窗格及旧配色=已恢复/保留细部；浅棕=估高体块；低薄红色/轮廓=通道或待核余边，不是实测楼高。**橙色C3、兰园是独立近似候选，不是已核准投影**。C3局部拟合RMS11.22m；兰园仅核组团外包范围，五栋独立位置未验证。

## 尚未完成，不隐藏
- 经管西翼11原对象、工培西翼4拆分部件与接受轮廓开口冲突，未激活。
- 二级学院另36旧件仍候选：C2部分10、C6西翼3、C9北翼3、行政D1全部20。D1穿楼通道不能堵住；保留样板不等于旧细节已迁完。
- 部分逐翼变换是显式近似；工培东翼横深调整约0.706、纵向基本不变。不能称无损精确配准。
- 兰园/工科为近似候选；桃园西6个指定源ID继续暂缓。
- 没有新做内部空间。未记录的庭院、地面通道、层高和道路净宽仍可能未知。

详见 `qa/RESTORATION_SCOPE.md`、各模块覆盖/变换/道路QA。88个新增匹配源以实际网格投影扣除样板，剩余未知形体只保守低示意，不用整高挤出遮住恢复细节。

## 坐标、AI接手与复现
EPSG:32650，固定原点E671709.6990725585、N3529586.400278158；本地X东/Y北/Z上，米；GLB标准Y-up变换X=x,Y=z,Z=-y。高程基准未知。**禁止为了单栋适配旋转底图、移动道路或改公共ID。**

本版为增量工程，避免重复发布稳定大模块：完整离线重建需保留仓库相邻的 `public_assets_v02/`。`DEPENDENCIES.json`列出固定输入及SHA；打开本版完整Blend/解压GLB则不需要旧目录。

- 各新增模块的 `geometry_database.json.gz` 与 `rebuild_clean.py`提供最终实际顶点/面/纯色，可独立重建。
- `massing/`包含本版实际剩余数据、配置、掩膜及生成脚本，非仅最初OSM摘录。
- `integration_inputs.json`指定所有模块及生医旧8对象排除规则。
- 模块存在后：`blender -b -t 2 --python scripts/integrate_v03.py`。
- 整包：`python3 scripts/validate_release.py`；冷开：`blender -b -t 2 --python scripts/validate_models.py`（先解压整体GLB）。
- `qa_support/`记录独立逐对象顶点/面/纯色及GLB回读结果。生产脚本仅在当前Blender4.3/Linux验证，未宣称跨平台全测。

唯一发布完整性清单是本目录 `ASSET_MANIFEST.json`。上版清单不冒称覆盖本版。重复mesh数据块名称为压缩包装省略，node对象名/ID及所有二进制几何不变；法线由viewer重算，几何未减面。
