# 桃园田径场实拍辅助细化候选版 · 2026-10-29

**这是可合入的独立增量候选，不是已经上线的全校园版本。** 保留 v17 及 v18 的全部既有建筑、道路、篮球场和原始体育场环面。当前新增 16 个 mesh；具体三角面数以 `qa/COLD_GLB_QA.json` 为准。

## 已做
- 准确对应桃园：OSM relation **11214072**，外边界 way **630436322**，原内场 way **817128568**。梅园 relation 11214073 没有改动。
- 在原红色环面内补 9 条闭环白边形成 8 条可辨识分道。8 道来自原 OSM running way 630436321 的 `lanes=8`，白线存在由官方 2023 照片佐证。
- 内场自然草色、轻微原创新纹理。纹理为程序原创，不包含校园照片像素。
- 足球边界、中线、中圈、禁区、罚球点、角区和两侧带网白色球门。
- 内场边缘白边。它是显示用边界标识，未把照片推成测量过的实体路缘高度。
- 白线/草地遵循既有地表绘制分层，球门/球网走正常深度测试；不靠透明叠片掩盖闪烁。

## 证据与估计必须区分
学校 2025-10-23 报道明确 2025-10-22 足球对抗赛位于九龙湖桃园体育场，图片可见白色带网球门、草地和外围低围栏。故可确认这里有足球使用，不是把 OSM 的旧 `sport=softball` 标签悄悄改成足球。原始标签仍保留在来源数据；足球用途另列证据。

**不是实测：** 分道曲线、各处道宽、白线宽、球场 100×64 m 的拟合布局、7.32×2.44 m 的球门标准形象及其位置/球网深度均为估计。旧 OSM 跑步线与内场边界并不允许直接套等宽跑道；本版本为避免侵入草地和道路，按原环面约束构造可变宽白线。**不能据此说跑道为精确 400 m，或每道宽 1.22 m；也不是赛事测绘模型。**

原红色环面的多边形折角、内场 hole 完整保留。没有用一个漂亮的标准椭圆替换地理基底，也没有整体移动、旋转或缩放校园。

## 尚未完成 / 不编造
- 外围围栏、出入口和看台：已确认存在低围栏/橙黄看台座椅，但精确位置、范围、数量、入口缺口仍缺可配准证据，本候选不虚构整圈围栏或新看台体量。
- 起跑线、跨栏标记、终点和分道数字：缺准确位置证据，未生成。
- 官方草地照片并不能证明固定割草条纹，本版本只用轻微自然色差，不添加整齐条纹。
- 不包含临时赛事横幅、观众及可识别人脸。
- 真实移动端 WebGL、远景球网抗闪烁、FPS 没有实机验证。Blender 渲染不是浏览器性能测试。

## 合入
参阅 `INTEGRATION.json`。只追加列出的 16 个对象，`replace_names=[]`；不得删除或重复加载原 v13 跑道、原内场、v16 篮球场。使用原地理本地米制坐标。新草地为原内场的地表显示覆盖，不改原 footprint。

地表顺序：原跑道 30；新草地 31；新跑道白线 34；新足球白线 35；内沿 36；原道路仍高于这些地表。地表只使用 ground pass（不写深度）；球门和网必须留在默认有深度测试的三维层。

## 复建
Python 3.12 + Shapely 2.x、NumPy、mapbox-earcut 2.1、Pillow；Blender 4.3.2 已验证。

```sh
python scripts/texture.py
python scripts/generate.py
python scripts/validate.py
blender -b --python scripts/build.py
blender -b --python scripts/cold_qa.py
```

纯复建现有资产只需运行 `build.py`，它使用已保存几何和原创纹理；无需访问原照片或网络。地理校验在双精度源几何进行；Blender 导出用单精度，构建时剔除量化后面积为零的三角形，冷回读已检查无退化面。

## 核查
- 全部 16 mesh、坐标和角色/绘制顺序通过 Blend → GLB → Blender 回读；无非有限坐标/零面积三角形。
- 原基底 4,928 个 mesh 的几何/变换在测试合入前后逐一指纹一致；新增16个，没有同名替换。
- 跑道白线全位于原红色环面；足球线和球门投影全在原内场；附近两条道路交叠面积为0。
- 同机位 `previews/BEFORE_AFTER.png`、俯视 `PLAN.png` 为模型渲染，不是网页截图。
- 以上是文件/几何核查，不是实地测量、物理碰撞模拟或手机性能验收。
