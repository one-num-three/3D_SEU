# 九龙湖校园模型 v19：桃园宿舍端部与田径场细节

这是以已发布 v18 为基底的完整源及增量补丁；本文件不代表网站已经部署。

## 本次变化
- 桃园1–2八栋：仅替换8个旧坡屋顶，增加48个端部屋面、墙带和窄窗对象；16端头、80个上部窄窗。保留六层窗、深色屋面板和v16窗梃修复。类型由项目航拍支持，尺寸/窗距/数量仍为照片辅助估计，不是逐栋测绘。
- 桃园田径场：新增16对象。原OSM relation11214072环面和内孔不动；lanes=8支持八道，增加9条闭合边线、足球标线、草地显示层及两座带网球门。足球用途由2025校方赛事图文支持，不修改原OSM softball标签。100×64m球场、线宽、球门位置和网格均估计；不宣称标准400m或等宽1.22m。
- 总作者网格4204→4260；其余4196对象几何、变换、材质参数未变，包括v18全部12条道路修正。网格数不是建筑数量。

## 查看
`assets/SEU_building_patch_v19.glb` 仅含64个新增/替换对象，不能用它替代整校模型。

宿舍三组同机位前后图在 `dorm_endheads/`；田径图在 `taoyuan_track/previews/`。均为离线模型审查渲染，不是网页截图或手机性能证明。来源、参数和复建脚本保留在两个独立模块中。

## 网页合入约定
保留fixed v14缓存及15/16/17/18全部增量，最后按 `data/REPLACEMENT_MANIFEST.json` 精确替8、追加64。不能回退旧道路或重复加载独立田径GLB。田径12地表绘制对象按extras.role=surface_paint进入ground pass（不写深度），顺序草31、跑道线34、足球线35、内沿36；4球门/网走正常三维深度。原v13红跑道保留。新增TURF是原内场footprint的显示覆盖，并非额外抬高的实体场坪。两灯必须继续覆盖layer0和1，避免再次出现黑球场。

保持v18四条柏油路颜色的加载顺序、缓存、触控和原桥透射/完整树默认。原桥7.5m照片比例估计标签不变。
