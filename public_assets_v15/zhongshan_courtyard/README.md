# 钟山书院：院落/分体纠错审查候选

状态：作为 v15 院落/分体体量纠错纳入；仍为明确标注的近似内部布局，不是竣工现状精模。原 v14 留档不变。

原 `SEU_B_OSMWAY_1488713409.001` 把 9095.25㎡ 的整个组团 envelope 填为 15m 高盒。官方近垂直施工图与后续多月航拍明确支持开放中庭、多体高低和不同屋面类型，不能保留为一个实心巨盒。

本候选是**同一原 OSM 组团内的近似内部布局**，不是逐栋精确投影恢复：五个屋面分体、独立东后低平平台与部分低廊；不把旧 R7 南长条、西整条硬迁过来。北高亭四坡，其余可见低翼双坡；中庭不抬高。前亭位于圆庭西南，拒绝把2025图中轴下方地下/阶口区域当亭挤出。未编未见窗、地下空间、完整入口或精确廊网。

- 主量投影约2034.99㎡；非主体空间约7060.26㎡，**不全是庭院**。
- 含檐口/低廊/薄圆环全投影约2348.42㎡。原组团外溢0、既有估宽道路交叠0；距映射道路约15.87m、简化水面约57.14m。
- 这些数值是模型和既有地图的检查，不是现场测距。蓝底是保留的原 envelope 显示层，不是建议新铺装。
- 近垂直图北施工边缘出框，原路宽为估计，岸线被树遮挡，**独立可靠控制点0，配准残差及绝对误差界均未知**。禁止把“所有几何在组团框内”改写为“逐楼配准通过”。
- 所有墙顶/屋脊高度、墙厚、门洞宽高、低廊支柱数量、圆庭尺寸仍为可编辑估计；前低亭和西转折内部位置不由2025板图唯一确定。
- 圆环仅表达可见圆形庭院景观，未认定为水池/喷泉。地下大底板不当高楼；当前构造完工状态未确认。
