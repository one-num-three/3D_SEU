# 橘园9–14 / 研究生宿舍三号院：实景立面增量

本包只含六栋：OSM 1056927545、1056927546、1056927547、1056927548、1056927549、1056927551。西侧一栋为橘园9，东侧由北至南五栋为10–14；不包含橘园1–8，不覆盖桃园/梅园已冻结细化包。`juyuan3_patch`是已拒绝的旧草稿，不能发布。

## 第一手依据

[东南大学基建处：九龙湖校区研究生宿舍三号院，2017-09-20](https://jbjsc.seu.edu.cn/2017/0920/c18724a198636/page.htm)。官方正文明确六层、西侧一栋东侧五栋、与旧宿舍围合及局部底层架空；该页竣工航拍已实际查看。图中可见连续浅色立柱和凹入分格立面、浅青坡檐、深色屋面板及端墙窄窗。

原图链接仅为引用（不打包原图）：https://jbjsc.seu.edu.cn/_upload/article/images/5c/e2/da6003c748de93774ebd630a9cbd/2922e1db-969c-4b35-b928-adb8125318e2.jpg

[同校2012项目介绍](https://jbjsc.seu.edu.cn/2012/1018/c7401a68949/pagem.htm)也说明六层、西1东5及局部底层架空，但2012图可能是建设/设计阶段，本包外观以2017竣工图为主，不当实测尺寸。

## 位置与参数

- 原单楼OSM是轻微不平行四边形，不能将其外接矩形直接拉高。尝试强行内接理想矩形会损失约14%面积，已拒绝。
- 本包按每栋原四边形内缩0.30m，做一致双线性坐标映射；保留原投影/中心位置/方向，所有墙、框、玻璃、栏杆、屋面均在原OSM足迹内。没有把围合整个院子实体填满。
- 旧注册mesh实际上5行窗；本包按官方六层重建。两长面每层15格，共180格，端墙上部另10格窄窗；窗格数、尺寸、节奏为参数估计，不宣称逐窗数准。
- 立面增加凹入区域、楼板、立柱、栏杆的独立实体层次；凹深1.35m、栏杆形式/间距和具体构造是对照片可见分层的估计，不是施工图确认。没有声称每一凹格的准确阳台功能。
- 墙体19.55m、屋脊21.90m、坡度及颜色均估计。官方只证六层，不证米制层高。
- 深色屋面板确实可见于本组官方照片，**不是因桃园有面板就复制过来**；面板类型/厂家/具体数量未确认，阵列数量为显示估计。
- 官方指出局部底层架空，但未取得逐栋明确架空区位置；本包不把六栋全部底层掏空，不编入口/连廊/室内。
- 实景年代2017，不宣称2026所有立面细节未改变。

## 集成与验证

`INTEGRATION.json`精确替换24个旧对象，追加54个新对象。不得同时保留该ID旧墙或旧屋顶，不应动其他18/12栋外的资产。原稳定ID不变。

`GEOMETRY_QA.json`及`EXPORT_QA.json`记录每栋全可见mesh投影越界面积0、原边界面积、新覆盖面积、六行窗及新增细节数量。此检查不是全校所有旧道路冲突审计。

Blender X东Y北Z上；EPSG:32650原点 E671709.6990725585 N3529586.400278158；GLB标准Y-up转换。几何数据库+rebuild_clean.py可独立复建。发布文件以最终FILE_MANIFEST为准，不含日志/.blend1/参考照片。截图为自主模型渲染，不是实拍。
