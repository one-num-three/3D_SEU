# 桃园田径场大看台 · 地理约束拟真候选 · 2026-10-29

**独立增量候选，尚不代表已发布到主站。** 用于 v19 校园主模型。原 16 个跑道/足球场细节完整保留；此包只补此前遗漏的西侧大看台建筑。

## 为什么之前没有看台
原 OSM 快照已包含 **way 1056927532**，标签是 `leisure=bleachers`，而不是 `building=*`。旧建筑抽取未把它生成主体。这不是需要凭空选位置的新建筑。

准确来源投影在 `data/FOOTPRINT_FRAME.json`。原六边形 footprint 保留，不用轴向包围盒替代。
- 地点：桃园田径场西侧，座席面朝东侧场地。
- 本地 bbox：X 734.655–765.010 m；Y 292.128–428.818 m。
- 沿实际长轴约 136.427 m；深度约 26.28 m。bbox 约30.36m宽是斜放结果，不是实际进深。
- EPSG:32650，本地原点 [671709.6990725585,3529586.400278158]；X东/Y北/Z上，单位米。

## 做了什么
16 个真实 mesh，100,604 个三角面，包含：
- 六边形地基、完整下部建筑和西侧服务楼体；不是只加座椅。
- 实体阶梯看台、上部走廊、分区通行台阶、端部楼梯。
- 橙黄座椅、扶手及前沿栏杆。
- 乳白色连续轻弧顶棚、白色管状桁架与后部支柱。
- 下部服务空间的示意门窗及分格。

## 实据与估计
**有依据：** 原快照 `leisure=bleachers` 精确对应这一地理位置；官方2017照片可见浅色顶棚、白色管状屋架、黄座椅；官方2025照片可见橙黄座椅和金属栏杆；体育系办公室位于看台下的说明证明下部不是空架子；2014体育系通知提到桃园田径场二楼会议室，支持有上下层使用空间。

**尚未测量：** 模型服务主体高8.5m、最高踏步8.72m、顶棚约12.5–14m。17排、6区、3264个模型座位只是可修改的建模参数，**不是实际排数、分区或容量**。屋顶曲率、桁架间距、柱数、楼梯位置、门窗数量与位置、内部使用布局也为估计，不是从照片完整复原。两层外观并不表示已掌握实际完整层数与层高。

已观察的是局部官方照片，并无可配准的完整屋顶俯拍。因此该候选是“位置有源、细节照片辅助、尺度明确标估计”，不是测绘级建筑，也不宣称精确复刻每个开间。

## 合入与复建
`INTEGRATION.json`列出精确16节点。全部为三维建筑层正常深度测试/写入；不放进地表无深度绘制层。只追加一次，不替换跑道、篮球场、宿舍、道路或原基底。检测已存在同名节点时应停下，避免重复加载。

```sh
blender -b --python scripts/build.py
blender -b --python scripts/cold_qa.py
blender -b --python scripts/render_preview.py -- path/to/complete_v19.blend
```

复建无需原照片或网络。Blender 4.3.2已验证。脚本的全部高度、排数和屋顶参数可修改；对外发布须重新做几何、图像和元数据检查。
