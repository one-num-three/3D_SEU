# 桃园1/2组团：位置不变的梯形纠正+实景屋面 v05-r2

本包替代未发布的 `dorm_patch`。请勿叠加旧首批，也勿采用r2构建过程中的失败文件。仅以最终 `FILE_MANIFEST.json` 核对完整冻结包。

## 实景依据
[谷德 / 东南大学九龙湖校区游泳馆，周琦工作室，2023-06-26](https://www.gooood.cn/natatorium-of-southeast-university-by-zhou-qi-studio-architects-and-engineers-associates-of-southeast-university.htm)。实际查看建筑师供图31、38、12：泳馆北侧两围合的八个直条宿舍、青绿色坡顶、深色屋面板阵列、浅墙、分层开窗可辨。38号俯视按泳馆/东侧球场/西侧食堂定位互证原OSM ID 630136421–428。照片年代2023，不声称2026未改造。

## 修正什么
旧模型虽然标称六层，实际窗mesh仅5行；旧直条楼注册成梯形，短边明显收窄，部分窗错位到端头。不能把错误旧mesh当作测绘约束。

本包在**不移动、不改原OSM坐标或真实footprint**的前提下：
- 以单栋OSM轮廓内缩0.60m矩形纠正旧梯形体块（不是整围合院子填实）；Z和六层总墙高仍为约19.55m估计。
- 重新参数化六行×两长立面×每行11格=132窗，保留立体窗框/玻璃并加中梃，较旧110格增加，而非降细度。具体窗格尺寸/节奏不是逐窗实测。
- 蓝绿坡顶、深色屋面板阵列、浅墙和深窗依据照片类型。屋脊22.45m、RGB、面板数、层距均显式参数估计。
- 无凭空入口、阳台、树木或街道装饰；端部楼梯间/连廊仍待更精确复原，因此不是宿舍最终完整模型。

所有最终可见部件（含墙、窗框、玻璃、坡顶、屋面板、中梃）的XY投影分别/合并检查在原OSM边界内，非只屋面检查。`GEOMETRY_QA.json`分列旧body面积、新body面积、屋面越界、最终全部几何越界；旧源错误不再隐藏。

## 集成与复建

`INTEGRATION.json`列32个旧对象精确替换名单；追加本包48个对象，八条稳定ID不变。不得删除其他模型。只用此最新包，旧首批dorm_patch为失效审查记录。GLB为标准Y-up；Blender X东Y北Z上；EPSG32650原点 E671709.6990725585 N3529586.400278158。

`rebuild_clean.py` 从 `geometry_database.json.gz` 复建独立blend/GLB；`build_patch.py`为参数生成器（numpy/scipy/shapely）。原始模型输入路径明确但不含私有用户资料。`.blend1`、日志与内部参考文件不是公开发布项。
