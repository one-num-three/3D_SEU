## 保守建模边界

原模型的九舍墙体也有错误梯形（长边约51m、短边约34m），原窗mesh实际5行，而不是六行。本次在原单栋OSM足迹内缩0.60m的直条范围纠正，保持原坐标基准和位置，不填院落，不放大真实边界。新倒角墙体、六层132格立体框/玻璃窗同步参数化，避免把坏窗位置从梯形投影到端墙。

屋顶分为中央浅坡和两个较高端部屋面，类型可观察；**端头精确进深、墙高、坡高仍为估计**。目前将端头简化为屋顶层次，不伪称完整楼梯间结构。主檐20.25m、主脊22.20m、端檐21.15m、端顶23.05m均估计，不是测绘高度；墙体整体约19.55m也仍是估计。立面窗距/尺寸、颜色并非逐窗校准。看不清的阳台、入口和连廊不凭空补全。

本批不加任何太阳能/集热面板；没有证据证明梅园九舍应与桃园面板阵列相同。真实地理位置与照片类型细化，不是全楼逐面还原完成。
