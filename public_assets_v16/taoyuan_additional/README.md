# 桃园篮球场：补齐外围18场（待统一集成）

当前基底已包含30个独立OSM篮球场面，2023设计院项目俯拍可数6列×5排；之前仅中间12场有线架网细节。本包按其余18个真实源面补齐完整模板细节，90 mesh／219312三角。**不是新增18块想象用地，也不是把通行空间全铺成球场。**

## 集成约束
- 前置：v15已有12场已共同纠正Z（−0.459m）；本包90件也已同样纠正一次。不要再次降低，不替换原12场、不加重复底板。
- `data/INTEGRATION.json` 是精确纯追加名单，replace_names为空。
- Blender本地X东/Y北/Z上，米；EPSG32650平移原点E671709.6990725585、N3529586.400278158。GLB由标准导出转换为X东/Y上/Z南。
- 18场仅刚体旋转/平移模板，无缩放、无减面。球圈中心与顶缘相对脚底仍3.04／3.05m；脚底Z=.001，现地面Z=−.004，保留5mm显示接合余量，不表示地形实测。
- 不改任何已冻结文件，不动网球、桥、道路、树或导航中心线。

- 30个pitch源ID为817128594–817128623；只新增18，精确几何与tags见GeoJSON。

## 重建与检查
`blender -b --python scripts/rebuild.py -- rebuilt.blend`
自包含`data/GEOMETRY_DATABASE.json.gz`保存局部mesh、世界矩阵、属性及原材质节点；不需原照片/私有备份。数据重建经过测试。`scripts/check_candidate.py`检查冷开及GLB往返；毫米网格边界漂移用一一三角匹配核验，不以bbox替代几何保留。
原程序Noise→Bump材质保留在Blender；标准glTF不支持程序节点，因此网页仍不复现`R7_BB_orange`、`R7_BB_court`微表面。没有另造UV/减面替代。
