## 复建
在工作副本中先用`taoyuan_additional/scripts/rebuild.py -- <taoyuan_additional/assets/SEU_Taoyuan_18_additional_v16.blend路径>`生成模块源；两个窗梃模块提供自包含数据库及`rebuild_clean.py`。随后`blender -b --python scripts/integrate_checkpoint.py -- <完整v15源路径>`。当前源和逐顶点修改数据公开，不依赖私有参考照片。完整冷开/补丁三角往返入口：`scripts/validate_checkpoint_blender.py`。
