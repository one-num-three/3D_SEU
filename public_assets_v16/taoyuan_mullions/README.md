# v16：桃园8栋窗梃共面修复（仅8个mesh）

## 根因

冻结v05-r2的生成器将每片玻璃的8顶点沿窗宽插值，直接作为窄窗梃。这样不仅继承玻璃前/后深度面，也继承上下端盖的Z平面。共132窗/栋×8栋；每窗4组同平面面配对，总4224组（每栋相当于1056个三角面落在这些平面上）。这会造成局部深度竞争/噪纹，**不是游泳馆log-depth问题的同义诊断**。

## 最小修复范围

仅替换 `SEU_B_OSMWAY_630136421` 至 `630136428` 的 `__V05_window_mullions`，共8对象。其他40个桃园对象——玻璃、外框、墙体、屋顶与板阵列——原几何指纹逐个从实际冻结blend重验未变。没有更改其它宿舍、泳馆、道路、球场或v15资产。

- 132窗/栋、每梃70mm宽、顶点数与面列表完全保留；没有减面、删窗或移动楼体。
- 南北立面按各自实际外法线处理，不能沿同一世界方向统一平移。
- 窗梃前表面比原玻璃可见面突出约35mm。
- 梃背部进入玻璃背后5mm，接入既有外框背板约10mm，不是悬空的装饰贴花。
- 梃端部向上下外框接合区各延伸60mm，总高1.80m，仍在原1.90m外框内；窗洞外界和原玻璃不改。
- **这些连接尺寸是合理显示构造估计，不是现场测量。**不据此升级建筑外观精确度。

原可靠OSM footprint完全不变。可见压条会相对旧玻璃凸出35mm，但全部新可见模型投影仍在原footprint内；不得把压条凸出描述为整楼位置变更。

## 验证结果

float32实际顶点：

| 检查 | 结果 |
|---|---:|
| 对应玻璃/窗梃同平面面配对 | 4224 → 0 |
| 可见玻璃面→新梃前面的最小法向距离 | 34.983mm |
| 所有对应平行平面的最小分离 | 5.027mm |
| 上下端盖最小Z平面分离 | 59.999mm |
| 与既有框背板最小接合深度 | 10.119mm |
| 8栋完整模型投影越界 | 0m² |
| 原其余40对象实际blend几何指纹 | 全部一致 |
| 8个新mesh法线绕序 | 全部向外 |

上表的“平面分离”不是固体之间的空气间隙：窗梃背部与框/玻璃接合区有意接触/嵌入。没有声称两个实体处处互不相交。

GLB已经实际重新导入Blender，逐顶点核对世界位置；结果见 `BLENDER_ROUNDTRIP_QA.json`。南北两侧均提供同相机设置的自主模型before/after实渲，after已目视复核，未附外部照片或私有路径标注。

## 集成

`INTEGRATION.json`列精确8个替换名。只替这些对象，**不可把本补丁当全校模型加载后删除旧场景**。保留 `UNTOUCHED_40.json`列出的原指纹；其它所有模块同样不在本次删除范围。

`VERTEX_DELTAS.json.gz`逐窗记录原→新每顶点位移；`COPLANAR_QA.json`逐窗提供外法线、前表面/端盖间距和接合深度。`geometry_database.json.gz`与`rebuild_clean.py`独立重建本8-mesh blend/GLB。`build_patch.py`需要旧冻结桃园数据库及原OSM来源；默认目录关系与项目一致。公开文件清单见 `FILE_MANIFEST.json`；日志和`.blend1`不发布。

投影沿用EPSG32650局部米：原点E671709.6990725585 N3529586.400278158，Blender X东Y北Z上；GLB标准Y-up。未改坐标基准。
