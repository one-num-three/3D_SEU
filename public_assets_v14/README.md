# v0.14 — 田家炳楼有限实景类型恢复

本增量保留此前校园模型，仅替换田家炳北条楼的默认体块，并给南U形旧楼补可见坡屋顶。不是整校新测绘，也不宣称田家炳完全实景复原。

## 实际修改
- 北条楼 OSM 300010601：删除旧 `SEU_B_OSMWAY_300010601.001` 默认块，增加墙芯、基座、窗框、玻璃及灰蓝四坡屋面5个组件。北墙顶仍12.12m，屋脊14.27m，均为估计。
- 南U形 OSM 300010619：保留原9件墙窗及其颜色、位置、高度，仅追加连续U形坡顶1个组件。原墙顶23.55m、旧六排窗未获本轮实景楼层确认；新脊26.70m亦为估计。
- 院洞保持开敞。照片中两侧窄连接的具体楼层/净空不足以确定，本批不虚构实体通道，不添加未见门洞或停车车辆。
- 北窗4排只是图中可见类型，**不等于已确认全楼只有四层**；每长面22列、窗距、坡度和颜色是模型估计，不是逐窗测绘。

官方来源：[物理学院田家炳楼全景](https://physics.seu.edu.cn/2020/0814/c23144a342261/page.htm)、[学院迎新身份说明](https://physics.seu.edu.cn/2022/1005/c23177a422325/pagem.htm)。已实际查看官方照片像素；原照片不在本包。旧北翼20.81m深度与当前12.52m地理轮廓不合，因此没有把旧宽楼压扁塞入，更没有恢复整组越界805㎡的旧配准。

## 数量、保留与验证
- 旧3971组件中3970组件几何、材质逐项保留；替换1、追加6，完整场景3976 mesh。组件数不是建筑数。
- 新增组件4268三角；扣除被替换块后完整场景2589673三角，净增4256。
- 全部新增几何投影位于对应源轮廓内，道路面交叠0。原道路、水面、跑道内孔、桥栏低开销显示所依赖的原资产均未修改。
- 冷开Blend、GLB回读1mm三角指纹一致；无嵌入图片、字体、Text、外部Library。
- 603程序树及8个可选自行车位置原样保留，通过最终建筑边界避让复核；不代表入口位置已测量。
- 金智C8仍是隔离诊断，不在这个增量中。

## 文件与复现
- `assets/SEU_building_patch_v14.glb`：浏览器增量，6个组件。
- `assets/SEU_campus_photorefined_v14.blend`：可直接在Blender打开的完整建筑/道路检查点。地表v04、程序树林v06为独立展示层，未嵌入此建筑检查点。
- `data/REPLACEMENT_MANIFEST.json`：精确替换和新增名字，必须保留v05–v13全部补丁；不得用这个小GLB替换整个校园。
- `tianjiabing_recovery/`：对应轮廓、修改后事实/几何数据库、参数、生成脚本、来源、限定与局部同机位前后图。
- `previews/V14_FULL_WITH_WOODLAND.png`：实际模型加原v04地表与603树的Workbench总览，不是手机/WebGL截图，也不验证真实手机FPS。
- `qa/`：旧组件/材质、导出、树/自行车、隐私与PNG像素校验。

在仓库根执行 `blender -b -P public_assets_v14/scripts/integrate_checkpoint.py -- public_assets_v13/assets/SEU_campus_photorefined_v13.blend`，源v13 SHA已固定在脚本内。模块可由其geometry数据库重建；未改动的历史依赖保持在原版本目录，不重复打包。`python public_assets_v14/scripts/validate_release.py`检查此增量所有文件及模块清单，不声称替代Blender冷开或手机性能验证。

坐标保持本地米：EPSG:32650，原点E671709.6990725585/N3529586.400278158；Blender东/北/上，GLB东/上/南；比例1。模型Z是本地显示高度，不是已知高程基准。
